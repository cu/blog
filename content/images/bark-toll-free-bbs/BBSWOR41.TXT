Okay, there's been a real dark age in 800 BBS's these past few months, so   
let me run through the list of BBS's that no longer serve the general 
public or shut down altogether, or just plain didn't make the list
because they weren't good enough:  Grace Thoughts, CAM, New Visions has
no more free trial by 800, Center Link, Serve-Line, Grateful Medical,
FRMS (Florida Recycling), and the 2nd number for Bark, are all down, but
there are plenty of other numbers to replace those.
   Some of these numbers run on Major BBS software, and enable the /P
function, so if any mischevious people want to play with that, Ive included
in the descriptions the BBS's that have that function (because I know what
its like).
   There are 9 numbers marked !NEW! which made the list, and 4 marked *NEW*
that made the list.  If there are any other numbers that you would want to
contribute to the list, just drop me a line on one of the numbers mentioned
later.

                Detailed Description
GULFLINE:  Because of abuse of file privileges, this BBS has closed off 
access to its sec. level 5 users.  This is a bummer, since chat, too, has
been taken away, and messages.  To tell you the truth, unless you're a 
hard-core enviornmentalist, this BBS pretty much stinks.  
Must be verified before full access is given.   Intended for enviornmental 
discussion.   
1-800-235-4662, N-8-1 ANSI  .QWK mail door:  no        4.0

ETA:   Due to abuse of the file privileges, this BBS has closed its only
real asset, the Upload file base and the Utilities file base.  The message 
base sucks, too.
1-800-828-5912, N-8-1 ANSI    .QWK mail door:  yes     5.0

BARK BBS:  Seems to be temporarily down for the moment, but could go back
up at any moment.  During this board's hey-day, it was the greatest source
of info, entertainment and ** lively ** discussion that a BBSing teen could
ask for.  Also for young musicians, poets, writers, etc.  The only
thing is they just keep coming back with that same message:  "We'll be back
online in so-and-so amount of days.  Will keep trying for nostalgic reasons
until it gets online again, sometime in the year 1999 or so...
1-800-333-0052, N-8-1 ANSI       .QWK mail door:  No  8.5

FSDO:  Very good file section, good message base, and supports RIP graphics.
Now has FIDONET!!!  busy alot, so you have to be persistent to get through.  
Aimed at aviators, but general public has access, too.  This is, by far,
the best BBS I have seen in a very long time.   PAGING ENABLED!!!
1-800-645-3736, N-8-1 ANSI        .QWK mail door:  yes  10.0

ME/U (Mind-Extension University):  This board, too, has entered the BBS dark
age.  Messages are gone.  Files are sub-standard, there is nothing for you in
this board unless you are interested in distance education.
1-800-688-6463, N-8-1 ANSI        .QWK mail door:  yes   3.0

RDL Electronics:  Mixed feelings on this board.  They cut down the files 
section alot except for a few files, but the message base is still lively
and instead of the line being busy all the time, you can actually get 
through now because they enforced use of the .QWK door.  I like it!
1-800-227-0391, N-8-1 ANSI        .QWK mail door:  yes  9.0

OERI:  educational board directed at educators.  Has good file base,
but no messages except for verified educators.  /P: yes
1-800-222-4922, N-8-1 ANSI        .QWK Mail Door:  no  8.0

ITE:  board for transportation people.  Good file base. Okay, but not the 
best.
1-800-982-4683, N-8-1 ANSI        .QWK mail door:  yes  7.0

RIBBS:  BBS for people interested in the postal service's offerings.  Okay
file base, and decent message base.  28 nodes!!! 
1-800-262-9541, N-8-1 ANSI        .QWK mail door:  yes  7.5

NBCI:  Great board.  Message base supports attachments.  Okay file base.  
Offers online chat, but from what I can tell, only has 2 stinking nodes at
this point.  Use Demo account to get 45 minutes time.  chat and /p
1-800-344-6224, N-8-1 ANSI        .QWK mail door:  Yes  8.0

FTA Online:  good board aimed at Transportation safety professionals.
has e-mail and public forums for discussing transportation and general
issues regarding various topics.  Check out the user submissions for a
few good files.
1-800-231-2061, N-8-1 ANSI        .QWK mail door:  No   7.0 

NASA:  BBS for programmers to exchange ideas for NASA's SBIR program.  Small
message base, but utilities files are pretty good.  
1-800-547-1811, N-8-1 ANSI         .QWK mail door:  Yes 6.5

Fedix & Molis:  government information system provided for the general public.
If information is what you want, this is for you.  800 # is only online from
Monday to Friday, 7 AM to 9 PM, Eastern Standard Time.
1-800-783-3349, N-8-1 ANSI         .QWK mail door: No  7.5

IBM C Set ++:  BBS aimed at people interested in IBM's C set ++ program.
okay file base,  large files!  okay message base.
1-800-874-2881, N-8-1 ANSI         .QWK mail door: No  6.5

Multi-Tech:  BBS with potential.  Small file base, but could increase with
time.  Okay BBS, but needs some work.
1-800-392-2432, N-8-1 ANSI         .QWK mail door: no  6.0

Nebraska Online:  Friendly users and good file base make this an okay BBS.
They really need new BBS software, though.  Oh well, its still not bad.
1-800-392-7932, N-8-1 VT100       .QWK mail door:  no   6.0

AT&T Global:  This board was really great until the sysops restricted chat.
Other than that, its ok for e-mail and some files. The /P function no
longer works here so you cant chat with anyone online, no matter how
hard you try.  But the E-mail is a good thing.  /P: no
1-800-692-8872, N-8-1 ANSI        .QWK mail door:  yes  7.5  

NEBBS:  educational board on Supercomputers.  Interesting.  Okay file base.
Message base contains only related topics.  So far, Im not impressed much.
1-800-447-6377, N-8-1 ANSI        .QWK mail door: No  6.5

Hayes Online:  Tech Support for Hayes modem owners.  Has numerous BBS lists,
okay file base.  Overall, not that bad a board.  
1-800-874-2937, N-8-1 ANSI         .QWK mail door: No  7.5

Dial Jan:  disability board for those interested in disabled subjects.  Not
bad.  Has okay message base.  Good place to plug your BBS list!
1-800-342-5526, N-8-1 ANSI          .QWK mail door: yes  7.5

Pennywise Shopping Online:  Business supply store.  Good for business owners.
1-800-752-3012, N-8-1 ANSI          .QWK mail door: no  6.5

SBA Online:  Business related BBS.  Has some files related to business.  The
good stuff is on the 900 line, though.  This BBS had its hot period, but
then took all the useful options away, so I didn't bother putting it
here until the recent "Dark Age" came.  It will probably be gone soon from
my list as more BBS's make comebacks and new ones come along.
1-800-697-4636, N-8-1 ANSI          .QWK mail door: no  6.5

WTIE:  Hazardous Waste Material Exchange.  Has some files, good messages,
but no access to private e-mail.  Good for enviornmental info.
1-800-544-1936, N-8-1 ANSI          .QWK mail door: yes  7.0

Epson Customer Support:  Decent file section.  Run on Major BBS software,
so /p function is offered at the moment, but that might not last.  Overall,
not that bad a BBS.  Must call during evening hours and note the   
extension.  You will get a voice answering machine, but just wait until
the 8777 is pressed and it will put you through.     /P: yes
1-800-234-1445,,,,8777, N-8-1 ANSI  .QWK mail door: no   7.0

National Institute of Health:  Excellent files with wide variety of in-
formation on health-related topics.  I was impressed.  No messaging.
1-800-644-2271, N-8-1 ANSI          .QWK mail door: no   7.5 

DWIE:  Same as WTIE except Drinking water topics are discussed and 
files are drinking-water related.
1-800-932-7459, N-8-1 ANSI          .QWK mail door: yes  7.0

Gateway 2000 Customer Support:  Decent little BBS with numerous lines
and some files.  /p function works  I think, but no one there seems
to leave theirs set to /p ok.  Could be good someday.
1-800-846-7562, N-8-1 ANSI          .QWK mail door: no   7.0

GTE Online:  okay files section, offering read-only Internet messaging 
but dont use the /p function here!  They monitor your /p messages and
kick you off if you abuse it by blocking your home phone.
1-800-483-4927, N-8-1 ANSI          .QWK mail door: no   7.0

Buddy BBS:  For blind people and their seeing-eye dogs, this BBS has
much potential.  The files section is fairly lively, the message
base is reasonably interesting, and its not too busy that much.
Only 1 line, though!  ARGH!  
1-800-449-2252, N-8-1 ANSI          .QWK mail door: yes  8.0 

CTDnet:  Excellent pay service for pretty much anyone, this BBS
has much to offer.  Internet E-mail, Teleconferencing (for registered
users only), Online Shopping, files, numerous forums, which include
Internet messages relayed to the CTDnet, Online catalogs, and many
other features.     /P: yes
1-800-318-5249, N-8-1 ANSI          .QWK mail door: no   9.0

National Kidney Cancer Association:  Dedicated to families and
victims of Kidney Cancer, and to the general public, this is the
most excellent new BBS I have seen recently.  The message base
could use some livening up, but the files are exquisite for the
BBS's purpose.  We all know how crappy sometimes these special interest
BBS's are (not all the time), but this one stands out.  Also, they
have chat, BUT... they only have 1 node.  They are working on
getting more lines installed, though, so this one could turn out
to be a major success, or another M-Link (remember them???)
1-800-280-2032, N-8-1 ANSI          .QWK mail door: soon 9.5

                Major BBS /P Function Note:
----------------------------------------------------------------------------
   It is your decision whether or not these BBS's stay up or not.  As most
of us know, the makers of The Major BBS by Galacticomm (sp?) left a very
fun little function in their BBS package called the paging function.
This is monitored on some BBS's like GTE online and a few others.  On
some it has been done away with altogether (AT&T Global).  I know how
it can be addictive chatting with people live, one on one, through
this overlooked glitch.  Because I do it too much myself.  Abuse of this
function is common.  Some sysops take it to heart, others dont mind at
all.  Its up to you what you do.  I cant stop you.  Heck, maybe we'll even
have a conversation sometime, but think about the fact that it cant last
forever on most of these BBS's before you use them solely for that purpose.
